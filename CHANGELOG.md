## [28.0.0.0] - Unreleased

### Added
- Added `Shopify.Catalog.Sync` to import company and market catalogs for one enabled shop through report 30115, with typed refusals and rollback on failure. Company catalogs require imported companies; market catalogs work without them. Catalogs absent from Shopify remain locally. Objects: enum/implementation 73732080, runner 73732081; mock-only tests 97533–97535 (#21; reassigned to avoid the merged MarkAsPaid test IDs).
- Added message type `Shopify.Payment.Sync` (enum value 73732110, codeunits 73732110/73732111): imports Shopify Payments payouts and payment transactions for one enabled shop by running report Shpfy Sync Payments (30105); granted through `SHOPIFY Full ori` (#32). A connector failure rolls back payout, payment transaction and Shopify log rows from that run, including commits the connector made between its steps. Unchanged counts can also mean the shop has no Shopify Payments account. Tests in codeunits 97550–97552.
- Added `Shopify.Company.Sync` (#18), enum/value and implementation 73732044, rollback runner 73732045: synchronizes companies through connector codeunit 30285, echoes the shop settings and local before/after counts. Only `SHOPIFY Full ori` grants execution. Explicit connector commits stay inside the rollback boundary. Mock dispatcher tests 97513, manual stub 97514, fixture-only MCP stub 97515 and seed/cleanup fixture 97516.
- `Shopify.Customer.Add`: create and link 1–100 selected BC customers through connector report 30112, with expected-count confirmation, existing-link handling and isolated per-customer failures. English help and Icelandic translations included. Objects: enumextension/value and implementation 73732140, runner 73732141; tests/stand-ins/fixture 97590–97593.
- `Shopify.Order.MarkAsPaid` (#26): confirmed, hard-to-undo Shopify payment write through public `Shpfy Orders.MarkAsPaid`; refuses repeats without refreshing the imported order. Enum/value and implementation 73732090; runner 73732091; success-marker table 73732090. Dispatcher tests 97530, mock subscriber 97531 and MCP fixture 97532. Explicit connector commits are ignored inside the rollback runner; a false result rolls back local writes.
- `Shopify.Metafield.Sync` (#35): loads definitions or sends changed values for one product, variant, customer or company using public connector codeunit 30418. Full permission only; validates shop, owner and expected local row count. Adds enum extension/value and implementation 73732060, runner 73732061, and mock tests/fixtures 97510–97512. Local counts do not imply sent counts; legacy types and empty values follow connector filtering.
- Added `Shopify.Payment.SyncDisputes` (#33): imports new disputes and refreshes open disputes for one enabled shop, returns shop-scoped before/after counts, and rolls back failed imports including explicit connector commits. Unchanged counts can also mean the shop has no Shopify Payments account. New enum/value and implementation 73732046, runner 73732047, tests 97517, mock 97518 and MCP fixture 97519.

- Prepared the first AppSource release with all nine Shopify operations, raised the Foundation minimum to 28.0.15.807 (release 28.0.15); context-sensitive help retains the Shopify app page URL because the app has no pages of its own (#62). No new objects. The release date is set when the release is approved.

- `Shopify.Order.CreateSalesDocument` (enum value 73732020, codeunit 73732020) refuses with `PreconditionFailed` before any change when the order's shop has Return and Refund Process = Auto Create Credit Memo, and the success response adds `documentStatus` (Open, Released, Pending Approval, Pending Prepayment), the same name in every language. Existing request and response fields are unchanged (#59). Tests in codeunit 97470. No new objects.
- Moved Shopify scaffold objects 70013400–70013402 to 73731950–73731952 and the app allocation to 73731950–73732149 (#54). Test objects remain in 97400–97599.
- Moved `Shopify.Order.CreateSalesDocument` enum extension, enum value and codeunit from 70013470 to 73732020 (the #54 mapping); restores the main build after #55 (AL0297) (#56).
- Numbered `Shopify.Fulfillment.Sync` enum extension, enum value and codeunits 73731980/73731981 (the #54 mapping of 70013430/70013431) when merging main into #46 (#29).
- MCP fixture codeunit 97471 now sets the fixture shop's "Order Attributes To Shopify" to false, so `Shopify.Order.CreateSalesDocument` can create the document without asking Shopify for an access token (#56).

- Added message type `Shopify.Product.SyncPrices` (enum value 73731990, codeunit 73731990): sends the Business Central prices of one shop's mapped products to Shopify through the connector's own price sync (report Shpfy Sync Products with Only Sync Price); granted through `SHOPIFY Full ori` (#9). Tests in codeunit 97440.
- Added message type `Shopify.Order.Import` (enum value 73731960, codeunits 73731960/73731961): fetches new and changed orders of one Shopify shop and imports and maps them by running report Sync Orders from Shopify (30104); granted through `SHOPIFY Full ori` (#23). Tests in codeunit 97472.
- Added message type `Shopify.Product.CreateItem` (enum value 73731970, codeunits 73731970/73731971): creates and maps Business Central items for the variants of one imported Shopify product through the connector codeunit Shpfy Create Item (30171); granted through `SHOPIFY Full ori` (#8). Tests in codeunit 97420.
- Added message type `Shopify.Refund.CreateCreditMemo` (enum value 73731955, codeunit 73731954): creates the credit memo of an imported Shopify refund through the shop's refund process (Shpfy RetRefProc Cr.Memo, which runs Shpfy Create Sales Doc. Refund 30246); granted through `SHOPIFY Full ori` (#30). Tests in codeunit 97401.
- Added message type `Shopify.Customer.Sync` (enum value 73732000, codeunits 73732000/73732001): imports Shopify customers and updates Shopify customers from Business Central for one shop, as the shop is set up, through the connector codeunit Shpfy Sync Customers (30123), the code behind the Sync action; granted through `SHOPIFY Full ori` (#16). A customer counts as updated or created only when the connector committed its work on it: writes are marked in the internal table `Customer Sync Marker ori` (73732000) inside the connector transaction, so a write a later step rolled back is reported, as are a new Shopify customer whose retrieval failed and an error the connector kept for the last customer. AC04 limit, accepted by Gunnar 21.11.2026 (decision d-20261121-shopify47-customer-sync-contract, option A): the connector does not expose a retrieval failure of an existing Shopify customer, when it fails before anything is written and a later customer succeeds, so that one case still answers Success; the help text (Notes) says so. Tests in codeunits 97450/97451 (stand-ins 97452/97453).
- Added message type `Shopify.Fulfillment.Sync` (enum value 73731980, codeunits 73731980/73731981): sends one posted sales shipment of a Shopify order to Shopify as a fulfillment by running the connector report Sync Shipments To Shopify (30109); granted through `SHOPIFY Full ori` (#29). Tests in codeunit 97430; the live Shopify success path is not covered by container tests.
- Added message type `Shopify.Order.CreateSalesDocument` (enum value 73732020, codeunit 73732020): creates the sales order or invoice of an imported Shopify order by running Shopify's report Shpfy Create Sales Orders (30103) for that one order; granted through `SHOPIFY Full ori` (#24). Tests in codeunits 97470 and 97471.
- Added message type `Shopify.Product.Sync` (enum value 73732010, codeunit 73732010): runs the connector's own product sync for one shop (report Shpfy Sync Products, not the price-only mode) to import products from Shopify and export changed items as the shop is set up; granted through `SHOPIFY Full ori` (#6). Tests in codeunit 97460.
- Added message type `Shopify.Product.AddItems` (enum value 73732040, codeunits 73732040/73732041): adds a selection of Business Central items (`itemNos`, 1 to 100) to one enabled Shopify shop as products by running the connector report Shpfy Add Item to Shopify (30106), the code behind the action Add Items on Shopify Products, with Sync Images and Sync Inventory off; per item the response says Added, AlreadyInShop or NotAdded (skipped by the connector); granted through `SHOPIFY Full ori` (#7). Tests in codeunit 97490 (stand-in 97491 for the live Shopify API, MCP fixture 97492).
- Added message type `Shopify.Product.SyncImages` (enum value 73732100, codeunits 73732100/73732101): imports Shopify product images or exports item pictures for one enabled shop by running the connector report Shpfy Sync Images (30107); the direction follows the shop setting Sync Item Images (`syncDirection` ToShopify or FromShopify), an optional `productIdFilter` limits the products, and a shop with Sync Item Images Disabled is refused with `PreconditionFailed`. Test codeunits 97540-97542 (#12).
- Added message type `Shopify.Inventory.Sync` (enum value 73732030, codeunits 73732030/73732031): sends the stock levels per location of one enabled shop to Shopify by running the connector report Shpfy Sync Stock to Shopify (30102); options `skipImport` and `variantIdFilter`; granted through `SHOPIFY Full ori` (#14). Tests in codeunit 97480.
